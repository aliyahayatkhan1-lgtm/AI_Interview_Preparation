# 🎯 AI Interview Preparation Assistant

An AI-powered Interview Preparation Assistant developed using Python and Streamlit that helps users practice interview questions, evaluate their answers, and improve their interview performance through personalized feedback.

## 🚀 Features

* 🎯 Multiple Job Role Selection
* ❓ Role-Based Interview Questions
* ✍️ Interactive Answer Submission
* 📊 Automated Performance Evaluation
* 💡 Personalized Feedback & Suggestions
* 📈 Interview Readiness Score
* 🖥️ User-Friendly Streamlit Interface

## 🛠️ Technologies Used

* Python
* Streamlit

## 📦 Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/AI-Interview-Preparation-Assistant.git
cd AI-Interview-Preparation-Assistant
```

### Install Required Libraries

```bash
pip install -r requirements.txt
```

Or install manually:

```bash
pip install streamlit
```

## ▶️ Run the Application

```bash
python -m streamlit run app.py
```

The application will automatically open in your default web browser.

## 📋 How It Works

1. Select a job role.
2. Answer the generated interview questions.
3. Submit your responses.
4. Receive an evaluation score.
5. Get personalized feedback and improvement suggestions.

## 📊 Evaluation Criteria

The system evaluates responses based on:

* Answer Length
* Detail Level
* Technical Depth
* Overall Completeness
